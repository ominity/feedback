# Ominity Feedback

Welcome to the public feedback and issue tracker for **Ominity**.

Use this repository to report bugs, request features, and help us improve Ominity.

> This repository is for feedback and issue tracking only. The Ominity application and its source code are maintained separately and are not part of this repository.

## 🐛 Found a bug?

Please [create a bug report](https://github.com/ominity/feedback/issues/new?template=bug.yml).

A useful bug report includes:

- What happened
- What you expected to happen
- Clear steps to reproduce the problem
- The affected part of Ominity
- Screenshots or screen recordings when useful
- Browser and device information when relevant

Before opening a new issue, please search the existing issues to see whether the problem has already been reported.

## ✨ Have an idea?

Please [create a feature request](https://github.com/ominity/feedback/issues/new?template=feature.yml).

We are especially interested in understanding the problem you are trying to solve and the outcome you would like to achieve. This helps us evaluate different ways of solving the same problem.

If a similar request already exists, feel free to add your use case or react to the existing issue instead of opening a duplicate.

## 🔒 Do not share sensitive information

Everything posted in this repository is **publicly visible**.

Never include:

- Passwords
- API keys or access tokens
- Authentication credentials
- Private URLs containing credentials or tokens
- Customer information
- Personal data
- Invoice or payment information
- Other confidential or sensitive information

If additional private information is required to investigate a problem, the Ominity team will arrange an appropriate way to provide it.

## 💬 What happens after submitting?

Reports and requests are reviewed by the Ominity team. We may ask for additional information, mark duplicate reports, or update an issue as its status changes.

Submitting a feature request does not guarantee that it will be implemented. Priorities depend on factors such as impact, demand, product direction, complexity, and available resources.

## About Ominity

Ominity is a headless content and commerce platform.

This repository contains **no Ominity application source code**. It exists solely as the public place for product feedback and issue reporting.
